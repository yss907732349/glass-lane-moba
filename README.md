# 透明单线 · 桌面竞技场

透明桌面悬浮、鼠键操作的 1 对 1 单路线 MOBA 试玩版。Windows 窗口周围透出桌面，默认只保留左上角控制条、紧凑技能栏和可收起的小地图。左上角可直接调整体缩放（50%～120%）和透明度（15%～100%），拖动角标可缩放，拖动把手可移动。置顶、隐藏、房间设置收在“···”菜单。浏览器可以联机，但不能透出真实桌面。

界面采用重新搭建的黑灰布局：底部居中双排战斗栏、角色资料式大厅和两列装备商店。血蓝数值与技能操作分区，冷却和学习状态保持清晰。场景保留深草绿、灰蓝河水、暖苔石路与角色原色，不做全画面灰度处理。

## 直接玩

安装 **release/GlassLane-0.2.0-Setup.exe** 后使用桌面或开始菜单快捷方式，也可双击 **开始游玩.cmd** 启动免安装版 **release/GlassLane-0.2.0-Portable.exe**。无需安装 Node。点击“单人练习”可以直接开局。安装完成不会自动弹出游戏。

联机时一人创建房间并设置密码，朋友连接同一个房间服务地址，再输入房间号与密码；双方准备后由房主开始。每方一个英雄，可以选择相同英雄。

局域网：房主在“设置”查看分享地址，朋友在设置中连接这个地址。默认端口 **4327**，占用时桌面版自动使用空闲端口，以设置显示为准。首次联机可能需要允许 Windows 专用网络访问。房间只保存在运行服务的电脑内，关掉房主服务后房间结束。

跨互联网：线上房间服务已部署到 https://glass-lane-moba.onrender.com ，0.2.0 客户端默认连接该地址，无需手动填写。双方使用同一服务、房间号与密码即可联机。原斗地主地址不支持此游戏。客户端支持通过 desktop/client-config.json 的 serverUrl 预设公网地址；旧版保存的 localhost 地址会自动迁移到新的默认地址，自定义远程地址保留。可参考 `docs/deployment.md`。断线暂停并保留座位 60 秒，刷新窗口可恢复，超时后回到房间。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | 右键地面 |
| 追击普攻 | 右键敌方英雄、小兵或建筑 |
| 英雄技能 | Q / W / E / R 先显示范围，左键确认释放；右键或 Esc 取消；指向技能必须点中敌人 |
| 学习 / 升级技能 | 技能上方的“＋”，或 Ctrl + Q / W / E / R |
| 治疗 / 闪现 | D / F 先选择、左键确认，独立冷却 |
| 走 A / 查看普攻范围 | A 或技能栏 A 按钮，左键敌人攻击，左键地面攻击移动；右键始终正常移动／追击 |
| 停止当前命令 | S |
| 装备商店 | B；Esc 关闭面板 |
| 回到英雄视角 | 空格 |
| 锁定 / 解锁跟随 | Y 或镜头按钮 |
| 移动视角 | 解锁后鼠标到边缘，方向键，或中键拖动；点击小地图定位 |
| 镜头缩放 | 战场上滚轮 |
| 收起 / 显示小地图 | M |
| 使用恢复药 | 1 或药瓶按钮，同时逐步恢复生命与法力 |
| 显示 / 隐藏窗口 | Ctrl+Shift+J |
| 恢复窗口与透明度 | Ctrl+Shift+0 |

游戏中间区域接收鼠标指令，即使部分画面透明也不会自动点穿到下面的软件。窗口外可以正常使用桌面。缩放与透明度自动保存，快捷恢复会还原为 100%。

## 对局

地图长 4800，可走区域宽 440，保留移动镜头与横向走位空间。防御塔射程 300，覆盖整条可走通道，无法从外侧无伤绕过；仍可冒着塔伤强行通过。每方一座防御塔、一个基地；塔被摧毁后基地才会受到伤害，拆掉敌方基地获胜。没有野怪。

中间河道加宽至 160，只有中路窄桥可正常步行，英雄和兵线都会绕到桥上；两侧水面只能使用位移越过，不能停留在河中。两岸共四片草丛，英雄进入后对敌方隐藏，普攻和指向技能无法选中；方向弹道、范围技能仍可命中，受伤后显形 3 秒。隐藏同步作用于小地图与联机状态。

视距为自己英雄周围半径 900。圈外战场遮蔽，单位与小地图标记隐藏，移镜头不能看见远方；远处兵塔仍正常作战。藏草受伤只能在对方视距内显形。死亡时视野暂留倒下位置，复活后移回己方出生点。

近战与远程小兵每 15 秒出发。金币随时间增长，亲手补掉敌方小兵额外获得金币；击杀英雄也有奖励。商店可在任意位置购买装备，最多六件，允许重复购买。死亡 9 秒后在己方基地附近满血满蓝复活。没有回城或泉水自动恢复，战场仍保留自然回蓝。

恢复药 100 金币一瓶，独立携带最多三瓶，不占装备栏。脱战满 5 秒后使用，8 秒内逐步恢复最大生命与最大法力各 50%；战斗中或脱战不足 5 秒时使用，只有 20% 药效，即各恢复最大值的 10%。完整药效期间重新参战，剩余恢复会降为 20%；已经按战斗药效使用的药不会中途变为完整药效。药效不能叠加，死亡会终止恢复。

角色最高 **10 级**，初始和每次升级各得1技能点。普通技能最高5级；R在4/7/10级可学习三档。技能数值、被动、基础属性、成长、护甲与魔抗均照录 MIT 开源 MOBA [Claude of Legends](https://github.com/killian01/claude-of-legends) 的固定提交 34fe718427d2726c92ed9063e694640e6d870013，只做坐标单位、等级上限与单线模式适配。四名英雄替换原来的两套自拟数值：

- **戴恩（Dain）**：热量战士，穿身炎拳、友军跃击护盾、强化普攻、中心眩晕陨击。
- **芬恩（Fenn）**：刺客，突刺、孤立双牙、烟幕隐身、大招突进后4秒内可原键返回。
- **阿什文（Ashvyn）**：射手，第三箭追加射击、锥形齐射、加攻速跃步、远箭禁锢与显形箭雨。
- **希尔拉（Sylra）**：法师，弹射荆棘、持续领域、可爆裂护盾、延迟禁锢与三级大招留场。

伤害加成、冷却等级公式和六件基础装备也使用来源原数值，移除旧法器的自拟20%技能增伤。保留你指定的DF、药水、视野、河道、兵线、塔基地和复活规则。来源原文、校验清单与全部适配详见 [四英雄说明](docs/source-heroes.md)。这保留了同一来源的英雄设计，并不等于来源在本项目1对1地图上的对局胜率已获验证。

## 素材与开源

四名英雄的像素外观使用 **Kenney Tiny Dungeon 1.0 / CC0**，包含从原静帧制作的轻量动作，之后可以替换原创美术。完整素材许可和来源保存在 `THIRD_PARTY_NOTICES.md`，开源 MOBA 项目调研见 `docs/open-source-research.md`。英雄玩法代码和数据现使用上述MIT来源，原始版权和许可已随客户端分发。外观使用独立CC0素材。

## 开发和后台测试

需要 Node.js 24、pnpm 11。该电脑系统默认 Node 较旧，开发时请使用 Codex 附带的 Node 24 或自行安装的新版。

```text
pnpm install
pnpm test
pnpm build
pnpm start
pnpm test:browser
pnpm run pack
```

`pnpm test:browser` 使用后台无窗口浏览器，不会打开可见游戏窗口。默认使用本机 Chrome，其他电脑可设置 `CHROME_PATH`。`pnpm desktop` 是手动打开游戏，不是后台测试。`pnpm test:native` 运行真实 Electron 隐藏窗口并验证画面、桌面桥接和机器人对局；打包版可运行 `node scripts/native-hidden-smoke.mjs --packaged=release/win-unpacked/透明单线.exe`。测试不创建托盘，不注册全局快捷键，不显示或聚焦游戏。

开发时分别运行 `pnpm server:dev` 和 `pnpm dev`；Vite 使用 5175 端口并代理到 4327。战斗、经济、技能和胜负由房间服务判定，客户端负责画面与输入。当前为可玩的功能原型，英雄平衡与动作精度后续可继续调整。

## 启动排错

0.1.1 在显示窗口前确认画面加载，启动失败提供重试界面；错误记录在用户数据目录的 startup-diagnostics.json。重复打开只显示已有客户端。线上连接暂不可用时仍能点“单人练习”切换本机服务；重新启动客户端会恢复默认线上地址，也可在连接设置重新填写。Render 免费服务空闲后会休眠，首次连接请等待唤醒。

## 0.1.3 房间连接修复

线上尚未连通时启动本机练习，退出后会自动恢复默认联机服务；恢复连接期间点击创建或加入会在连通后继续。大厅和房间显示当前服务，双方需确认地址相同，并使用房主当前的房间号与原密码。粘贴的六位房间号支持全角数字和空格。若服务重启清空房间，请由房主重新创建并分享新号码。密码仍严格匹配，不会绕过或放宽验证。

0.2.0 使用 glass-lane-v2 协议，双方需更新客户端，服务也需更新为0.2.0。旧协议创建、加入与重连会收到明确的更新提示。
